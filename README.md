## 🚀 How to Run Locally

### Option A: Localhost Web Server (Recommended)
1. Open PowerShell or Command Prompt in the project folder:
   ```bash
   node server.js
   ```
2. Open your web browser and go to:
   ```text
   http://localhost:3000/
   ```

### Option B: 1-Click Desktop Shortcut
- Double-click the **`Open_Portfolio.url`** shortcut file on your Desktop or in the project folder to launch `http://localhost:3000/` automatically in your default browser.

### Option C: Direct File Mode (Zero Server Needed)
- Double-click **`index.html`** in Windows File Explorer to open the portfolio offline directly in Chrome, Edge, Brave, or Firefox.

## 🌐 How to Deploy Publicly Online

### Method 1: Deploy to Vercel (Fastest — 1 Minute)
1. Go to **[vercel.com](https://vercel.com)** and sign in with GitHub.
2. Click **"Add New Project"**.
3. Drag and drop your **`My Portfolio - MANAN`** folder directly into Vercel.
4. Click **Deploy**. Within 15 seconds, you will receive a free public URL (e.g. `https://manan-portfolio.vercel.app`) to share with anyone!

### Method 2: Deploy to GitHub Pages (Free Hosting)
1. Open terminal inside the project directory:
   ```bash
   git init
   git add .
   git commit -m "feat: Cybercity portfolio for Manan Joshi"
   git branch -M main
   git remote add origin https://github.com/Manan-1401/portfolio.git
   git push -u origin main
   ```
2. On GitHub, navigate to **Settings > Pages**.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Your website will be live at `https://manan-1401.github.io/portfolio/`!
